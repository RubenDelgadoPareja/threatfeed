# AGENTS.md

Repo-level instructions for coding agents working on ThreatFeed.

## Agent skills

### Issue tracker

Issues and specs live in GitHub Issues on `RubenDelgadoPareja/threatfeed`,
managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`,
`ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` and `docs/adr/` at the repo root, created lazily
by `/domain-modeling`. See `docs/agents/domain.md`.
